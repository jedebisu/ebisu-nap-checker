# G-MAPS

G-MAPS is a NAP-checking demo app for **Globe Telecom**, rebranded from the EBISU T&A (Selfie Attendance) project. It provides a facility map viewer where users can look up Globe NAP (Network Access Point) locations via a web-based interface and an Android companion app.

**Related docs:** See [spec](./docs/spec.md) and [implementation plan](./docs/plan.md).

Build/deploy commands will be added by later tasks in this SDD sequence.
